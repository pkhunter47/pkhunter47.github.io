# Protik Biswas — Portfolio

A responsive, animation-rich static portfolio built for GitHub Pages.

The package includes original generated background artwork, a research portfolio, a UI/UX gallery, a downloadable CV, publication evidence, and a code playground with Python, C++, and interactive Three.js experiments.

## Publish on GitHub Pages

1. Create a public repository named `pkhunter47.github.io`.
2. Upload the contents of this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. The site will be available at `https://pkhunter47.github.io/`.

No build step or package installation is required.

## Local preview

Run `python -m http.server 8080` inside this folder, then open `http://localhost:8080`.
